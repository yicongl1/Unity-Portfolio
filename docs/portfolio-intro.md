# 个人网站简介

## 短版

Unity 学习作品集，收录 2021–2022 年完成的 4 个 Unity 原型和 8 个 C# 练习。项目覆盖 3D 滚球与解谜、2D 竖版射击、无限跑酷和第三人称角色控制，涉及 Rigidbody 物理、碰撞与触发器、UGUI、场景管理、协程、Animator、粒子与音频。三个 Windows 版本放在仓库的 `release-assets/` 目录，也可以在 GitHub Releases 下载。

## 长版

2021 年到 2022 年，我从 C# 基础和 Unity 入门开始，逐步完成了 4 个可玩的 Unity 原型和 8 个 C# 控制台练习。

这些项目大多从教程和课堂练习出发，后来加入了关卡设计、UI、状态机、粒子、音效和自己的玩法调整。其中既有由 3D 滚球、迷宫和拉箱子解谜组成的街机合集，也有 2D 竖版射击、红绿换色的无限跑酷，以及一个用于理解输入、朝向和位移关系的第三人称角色移动 Demo。

代码方面，我主要使用 C# 和 Unity 2021.3 LTS，熟悉 MonoBehaviour 生命周期、Rigidbody 物理、碰撞与触发器、UGUI、SceneManager、协程、Animator、ParticleSystem 和 AudioSource。C# 练习部分则覆盖了面向对象、List/Dictionary、单例、加权随机、简单状态机和回合制战斗逻辑。

## 项目短句

- 滚动球街机合集：用一个主菜单串联滚球闯关、迷宫和拉箱子解谜三个小游戏。
- 飞龙射击：2D 竖版射击，包含连发冷却、随机刷怪、受击反馈和 Boss 巡逻。
- 变色跑酷：3D 无限跑酷，通过跳跃和红绿换色躲避异色平台。
- 角色移动：第三人称移动 Demo，练习输入、朝向与位移的基本关系。
