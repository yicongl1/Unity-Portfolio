# C# 基础练习

学习 C# 语法和面向对象时写的 8 个控制台程序，按学习顺序编号。每个目录都是一个独立的 .NET Framework 4.7.2 控制台项目。

| # | 目录 | 主要内容 | 关键概念 |
|---|------|----------|----------|
| 01 | `01-boxing-singleton` | 拳击手对战 | 单例、对象数组、`Random`、属性、状态 |
| 02 | `02-singleton-and-arrays` | 随机数组打印 | 单例、方法重载、一维/二维数组 |
| 03 | `03-object-copy` | 学生对象复制 | 构造函数、对象复制、命名参数 |
| 04 | `04-list-operations` | `List` 增删改查 | 集合遍历、筛选、原地删除 |
| 05 | `05-gacha-draw` | 加权抽卡 | 累计概率、随机数、权重 |
| 06 | `06-turn-based-battle` | 回合制战斗 | 技能/状态、伤害公式、持续治疗、回合循环 |
| 07 | `07-dictionary` | 字典操作 | `Dictionary` 增删改查、遍历时安全删除 |
| 08 | `08-water-bottle` | 水壶模拟 | 类与对象、状态约束、交互菜单 |

## 各练习说明

### 01 - 拳击手对战

- `BoxerManager` 用懒加载单例管理最多 100 个 `Boxer`。
- 对战中每次攻击有 1/4 概率被闪避。
- 拳击手首次死亡会满血复活一次；血量低于 30 时攻击力翻倍，回到 30 以上后解除。

### 02 - 单例与数组

- `Utils` 单例提供随机数、一维数组打印、二维数组打印三个方法。
- `PrintArray` 使用重载区分一维和二维数组。
- 练习了二维数组的遍历顺序与行列下标。

### 03 - 对象复制

- `Student` 用静态 `index` 自动编号。
- `Copy()` 返回一个字段相同的新对象，用来观察引用类型与对象复制的区别。
- 调用 `ChangeScoreRank(score: 60, rank: 10)` 练习命名参数。

### 04 - List 操作

- 每隔一个元素自增、筛选偶数/奇数、原地删除偶数。
- 重点在于删除元素后下标回退，避免漏掉相邻元素。

### 05 - 加权抽卡

- 每张卡有 `power` 权重，`powersum` 为总权重。
- `Draw()` 在 `[0, powersum)` 中取随机数，再依次减去权重，落在哪个区间就返回哪张卡。
- 练习了「权重 → 累计概率」的实现方式。

### 06 - 回合制战斗

这是 8 个练习里最完整的一个，也是后来做游戏逻辑的基础。

- `Character`：生命、攻击、防御、暴击率（预留）、技能列表、状态列表。
- `Skill`：普通攻击、吸血、治疗、持续治疗（HoT）。
- `State`：持续治疗 / 持续伤害，带剩余回合数与来源角色。
- 伤害公式：`攻击 × 技能倍率 × (1 - 防御 / (300 + 防御))`，保证防御再高也不会完全免伤。
- 战斗循环：玩家输入数字选技能，AI 随机选技能，结算状态后判断胜负。
- 用 `Console.ForegroundColor` 区分双方输出。

### 07 - Dictionary

- 练习 `Add`、索引器赋值、`ContainsKey`、`Remove`、`foreach` 遍历。
- 演示了「遍历时不能直接删除」的问题：先把要删除的 key 收集到 `List`，再统一删除。

### 08 - 水壶

- `Bottle` 类包含容量、当前水量、温度三个状态。
- 倒水、加水、加热都会做上下限约束。
- 用三个不同容量的水壶练习对象数组/菜单交互。

## 如何运行

这些项目使用旧式 `.csproj`（`TargetFrameworkVersion v4.7.2`），推荐用 Visual Studio 2019/2022 打开对应的 `.csproj` 后直接运行。

如果本机没有 .NET Framework 4.7.2，可以：

1. 新建一个 .NET 控制台项目；
2. 把对应目录下的 `.cs` 文件复制进去；
3. 保留 `Main` 方法所在文件，运行即可。

`Properties/AssemblyInfo.cs` 只包含程序集元数据，不是运行所必需的。
