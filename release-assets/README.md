# 可执行版本

三个游戏的 Windows 64 位构建包，同时发布在 GitHub Releases。

| 文件 | 游戏 | 大小 |
|------|------|------|
| [rolling-ball-arcade.zip](rolling-ball-arcade.zip) | 滚动球街机合集 | 61.8 MB |
| [dragon-shooter.zip](dragon-shooter.zip) | 飞龙射击 | 26.2 MB |
| [color-runner.zip](color-runner.zip) | 变色跑酷 | 25.6 MB |

解压后双击对应目录下的 `.exe` 即可运行。如果 Windows 弹出 SmartScreen 提示，选择「更多信息 → 仍要运行」。

这些包来自学习阶段的构建，不包含后来对源码的小修复。想体验最新行为，可以用 Unity 打开源码工程运行。
